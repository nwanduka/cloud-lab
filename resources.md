# Learning Resources
### DevOps Prerequisites Course - *KodeKloud*
⏱️ 2h 23m | 🎯 Complete Beginner | [Watch on YouTube](https://youtu.be/PfjVXb-YXbQ?si=2Cyw31T1CJ-eKff1) | [Practice Labs](https://kodekloud.com/studio/labs/devops) | [Full Course](https://kodekloud.com/courses/devops-pre-requisite-course/)

This course does exactly what its name suggests. It demystifies the foundational concepts you need before diving into DevOps proper. It's part of the [DevOps Engineer learning path](https://kodekloud.com/learning-path/devops-engineer) on KodeKloud. The free YouTube version is complete enough to help you decide if you want to subscribe to KodeKloud's full platform.

It covers Linux basics, provides a solid overview of common DevOps tools and how they fit into each stage of the development process, and touches on other essential topics. There’s also a follow-along lab environment included (useful if you don’t already have one set up on your laptop), so you can practice after each section. The course is beginner-friendly, so you don’t need any coding background to understand it.

I highly recommend.
